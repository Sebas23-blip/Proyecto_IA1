# *Clasificación de especies raras*
Proyecto de Inteligencia Artificial I
![banner](https://gitlab.com/crisdifran122/clasificacion-de-especies-raras/-/raw/f8bc519df4b324005cebcca9b39f3eca04635507/banner_proyecto.png)

## *Autores*
Jorge Sebastian Fuquene, Cristian Diaz Franco

## *Objetivo general*
Comparar clasificadores tradicionales y métodos no supervisados para la identificación automática de especies raras mediante características visuales.

## *Dataset*
* [Imageomics rare species](https://huggingface.co/datasets/imageomics/rare-species)

## *Modelos*
* GaussianNB
* DecisionTree
* RandomForest
* SVClassifier
* K-Means
* DBSCAN
* Clustering Jerárquico
* DNN
